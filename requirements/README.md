# 中汇企业官网需求文档

本文档详细描述了中汇企业官网系统的功能需求，包括管理后台和微信小程序两部分。

---

## 一、系统概述

### 1.1 项目背景
中汇企业官网系统是一个企业信息展示平台，包含以下三个模块：
- **后端服务**：提供 API 接口，使用 Express.js + MySQL 技术栈
- **管理后台**：用于管理员管理轮播图、文章、联系表单等内容
- **微信小程序**：面向 C 端用户，展示企业信息、案例、问答等

### 1.2 技术架构

| 模块 | 技术栈 | 访问地址 |
|------|--------|----------|
| 后端服务 | Express.js + MySQL | http://localhost:3000 |
| 管理后台 | 原生 HTML + JS | http://localhost:3000/admin |
| 微信小程序 | 微信小程序框架 | 微信开发者工具 |

## 二、管理后台需求

### 2.1 登录功能

#### 功能描述
管理员通过用户名和密码登录管理后台。

#### 场景操作步骤
1. 打开浏览器，访问管理后台登录页面 `http://localhost:3000/admin/login.html`
2. 在用户名输入框中输入管理员用户名
3. 在密码输入框中输入管理员密码
4. 点击「登录」按钮
5. 如果用户名和密码正确，页面跳转到管理后台首页
6. 如果用户名或密码错误，显示错误提示信息「用户名或密码错误」

#### 验证规则
- 用户名：必填
- 密码：必填

---

### 2.2 退出登录

#### 功能描述
管理员退出当前登录状态。

#### 场景操作步骤
1. 在管理后台首页，点击右上角的「退出登录」按钮
2. 清除登录状态，页面跳转到登录页面

---

### 2.3 修改密码

#### 功能描述
管理员修改登录密码。

#### 场景操作步骤
1. 在管理后台首页，点击右上角的「修改密码」按钮
2. 弹出修改密码模态框
3. 在「当前密码」输入框中输入当前密码
4. 在「新密码」输入框中输入新密码
5. 在「确认新密码」输入框中再次输入新密码
6. 点击「保存」按钮
7. 如果当前密码错误，显示错误提示
8. 如果两次新密码不一致，显示错误提示
9. 保存成功后，显示成功提示，2秒后自动关闭模态框

#### 验证规则
- 当前密码：必填
- 新密码：必填
- 确认密码：必填，且需与新密码一致

### 2.4 轮播图片管理

#### 功能描述
管理首页轮播展示的图片，支持添加、编辑、删除、排序功能。

#### 场景操作步骤

**查看轮播图片列表**
1. 登录管理后台，默认进入「轮播图片管理」页面
2. 页面展示轮播图片列表，每页显示 10 条
3. 列表显示：ID、图片缩略图、标题、排序序号
4. 列表底部显示分页控件（上一页、页码、下一页）
5. 点击「上一页」或「下一页」或具体页码，加载对应页的数据

**添加轮播图片**
1. 在轮播图片管理页面，点击「添加轮播图片」按钮
2. 弹出添加模态框
3. 点击「上传图片」按钮，选择本地图片文件
4. 图片上传成功后，页面显示图片预览
5. 在「标题」输入框中输入轮播图标题
6. 在「排序」输入框中输入排序序号（数字越大越靠前）
7. 点击「保存」按钮
8. 保存成功后，模态框关闭，列表刷新显示新添加的轮播图

**编辑轮播图片**
1. 在轮播图片列表中，点击某条记录的「编辑」按钮
2. 弹出编辑模态框，表单中预填了该轮播图的现有数据
3. 可以修改标题、排序
4. 如果需要更换图片，点击「上传图片」重新选择
5. 如果不更换图片，保持原有图片不变
6. 点击「保存」按钮
7. 保存成功后，模态框关闭，列表刷新显示更新后的数据

**删除轮播图片**
1. 在轮播图片列表中，点击某条记录的「删除」按钮
2. 弹出确认对话框，提示「确定要删除吗？」
3. 点击「确定」按钮
4. 删除成功后，列表刷新

---

### 2.5 文章管理

#### 功能描述
管理案例分享和问答文章，支持添加、编辑、删除、搜索、分页功能。

#### 场景操作步骤

**查看文章列表**
1. 在导航栏点击「文章管理」，进入文章管理页面
2. 页面展示文章列表，每页显示 10 条
3. 列表显示：ID、图片缩略图、标题、文章类型、发布日期、浏览次数
4. 列表底部显示分页控件

**搜索文章**
1. 在文章类型下拉框中选择筛选条件（全部类型 / 案例分享 / 问答文章）
2. 在搜索框中输入标题关键字
3. 点击「搜索」按钮
4. 页面显示符合筛选条件的文章列表
5. 如果没有符合条件的数据，显示「暂无数据」
6. 点击「重置」按钮，清空搜索条件，重新加载全部数据

**添加文章**
1. 在文章管理页面，点击「添加文章」按钮
2. 弹出添加文章模态框
3. 点击「上传图片」按钮，选择文章封面图片
4. 在「标题」输入框中输入文章标题
5. 在「文章类型」下拉框中选择文章类型（案例分享 / 问答文章）
6. 在富文本编辑器中输入文章内容
7. 在「发布日期」选择器中选择发布日期（可选）
8. 点击「保存」按钮
9. 保存成功后，模态框关闭，列表刷新

**编辑文章**
1. 在文章列表中，点击某条记录的「编辑」按钮
2. 弹出编辑模态框，表单中预填了该文章的现有数据
3. 可以修改标题、文章类型、内容、图片
4. 点击「保存」按钮
5. 保存成功后，模态框关闭，列表刷新

**删除文章**
1. 在文章列表中，点击某条记录的「删除」按钮
2. 弹出确认对话框
3. 点击「确定」按钮删除
4. 删除成功后，列表刷新

#### 功能描述
查看用户通过微信小程序提交的联系表单信息。

#### 场景操作步骤

**查看联系表单列表**

2. 页面展示用户提交的联系表单列表，每页显示 10 条

4. 列表底部显示分页控件

## 三、微信小程序需求

### 3.1 首页

#### 功能描述
展示轮播图、快捷入口、案例分享列表。

#### 场景操作步骤

**查看轮播图**
1. 打开微信小程序，默认进入首页
2. 页面顶部的轮播图自动播放
3. 左右滑动可以切换轮播图
4. 点击轮播图可以跳转到对应文章详情（如果有关联）

**查看快捷入口**
1. 在轮播图下方显示四个快捷入口图标
2. 分别是：互惠美国、澳洲whv、美国营地、我要咨询
3. 点击「我要咨询」图标，跳转到联系我们页面

**查看案例分享列表**
1. 在快捷入口下方展示案例分享列表
2. 默认显示最新的 10 条案例分享
3. 每条记录显示：封面图片、标题、发布日期
4. 点击某条案例分享，跳转到案例详情页面

**查看更多案例**
1. 点击「查看更多案例」按钮
2. 跳转到案例分享列表页面

**搜索功能**
1. 在首页顶部的搜索框中输入搜索关键词
2. 点击搜索按钮或按下回车键
3. 跳转到搜索结果页面，显示包含关键词的文章

---

### 3.2 案例分享列表

#### 功能描述
展示所有案例分享文章，支持分页加载。

#### 场景操作步骤

**查看案例列表**
1. 在首页点击「查看更多案例」，进入案例分享列表页面
2. 页面默认加载最新的 10 条案例分享
3. 每条记录显示：封面图片、标题、发布日期
4. 页面显示「加载中」提示（数据加载过程中）
5. 加载完成后，显示案例列表

**分页加载**
1. 手指向下滑动屏幕到底部
2. 自动加载下一页的数据（每页 10 条）
3. 页面底部显示「加载中」提示
4. 如果没有更多数据，显示「暂无更多数据」提示

**查看案例详情**
1. 点击某条案例分享记录
2. 跳转到案例详情页面
3. 页面显示：封面图片、标题、发布日期、浏览次数、文章内容

1. 手指向下滑动屏幕到底部

4. 如果没有更多数据，显示「暂无更多数据」提示

**查看 QA 详情**

### 3.4 联系我们

#### 功能描述
用户填写联系表单，提交个人信息。

#### 场景操作步骤

**填写联系表单**
1. 在小程序底部导航栏点击「联系我们」
2. 页面显示联系表单，包含以下字段：
   - 姓名（必填）
   - 生日（必填）
   - 意向项目（必填，可多选：互惠美国、互惠澳洲、澳洲WHV工作、美国Camp、其他）
   - 最高学历（必填）
   - 符合条件（必填，可多选：无犯罪记录、未婚未育、近五年内无心理疾病/手术史、有中国C1C2驾照）
   - 英语水平（必填）
   - 英语成绩（当选择"有语言成绩"时必填）
   - 育儿经验（必填）
   - 所在城市（必填）
   - 联系方式（必填）

**提交表单**
1. 填写完所有必填字段后
2. 点击「提交」按钮
3. 如果有必填字段未填写，弹出提示「请填写/选择xxx」
4. 验证通过后，显示「提交成功」提示
5. 表单数据提交到服务器
6. 提交成功后，自动重置表单为空白状态

**重置表单**
1. 点击「重置」按钮
2. 表单所有字段清空，恢复为初始状态

## 四、数据模型

### 4.1 轮播图表（carousel）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT | 主键，自增 |

## 六、非功能性需求

### 6.1 性能要求
- 页面加载时间不超过 3 秒
- API 响应时间不超过 1 秒

### 6.2 兼容性要求
- 管理后台：支持 Chrome、Firefox、Safari、Edge 等现代浏览器
- 微信小程序：支持微信 iOS 和 Android 最新版本

### 6.3 安全要求
- 管理员登录需要验证用户名和密码
- 敏感信息（如密码）不在客户端存储
- API 接口使用参数化查询防止 SQL 注入
